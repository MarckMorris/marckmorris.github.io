InfraScan AI

The platform I founded in September 2026 and run end to end, from Terraform to on-call.

InfraScan AI gives small and mid-size U.S. businesses the SRE, cloud security and FinOps coverage they can't staff. Customers connect GCP, AWS or Azure with keyless read-only access. The platform scans and scores their accounts, watches uptime and SLOs, routes incidents to their on-call, runs guarded fixes and sends reviewed reports.

I made the architecture and security decisions and wrote the code with AI-assisted tooling that I review and test. It runs on GKE Autopilot, deployed with Terraform and Argo CD.

Platform as code

  • Terraform for dev and prod: private GKE, Cloud SQL with PITR and a database per service, Pub/Sub with dead-letter topics.
  • Global load balancer behind Cloud Armor with OWASP rules, rate limits and Adaptive Protection.
  • Identity Platform with MFA, Secret Manager and a rotating Cloud KMS key.

Delivery and supply chain

  • Argo CD app-of-apps; manifests and network policies generated from one service catalog.
  • GitHub Actions with keyless Workload Identity Federation, pinned actions and dependency audits.
  • Images signed with cosign; Kyverno admits only signed, non-root images.

Reliability and security

  • Event outbox to Pub/Sub, autoscaling, disruption budgets and KEDA scanners from 0 to 5.
  • Uptime checks, SLOs, burn-rate alerts, PagerDuty paging and postmortems.
  • Per-tenant federation, workload-identity tokens between services, default-deny networking.
